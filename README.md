# LearnHub

AI-powered collaborative learning + competitive programming platform. MERN + Gemini.

See [MASTER_PROMPT.md](../../../Downloads/MASTER_PROMPT.md) for the full spec.

## Quickstart

Prereqs: Node 20+, MongoDB running locally on `mongodb://localhost:27017`.

```bash
# Backend
cd backend
npm install
npm run dev          # http://localhost:5000

# Frontend (in another terminal)
cd frontend
npm install
npm run dev          # http://localhost:3000
```

Email is currently stubbed to log verification/reset links to the **backend console**. To wire a real provider later, edit `backend/src/services/mailer.ts`.
